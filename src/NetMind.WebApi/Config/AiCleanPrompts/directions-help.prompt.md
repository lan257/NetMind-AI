# NetMind 应用使用说明书

版本：1.0 | 更新时间：2026-05-10

NetMind 是一个基于 AI 的知识网络构建与可视化工具，帮助你把文本、文档或需求整理为标准结构，并以思维导图/知识图谱形式存储、展示和编辑。

---

## 1. 安装与启动

### 1.1 环境要求

- **后端**：.NET 8 SDK
- **数据库**：PostgreSQL
- **前端**：Node.js 18+、npm

### 1.2 数据库准备

1. 安装并启动 PostgreSQL。
2. 创建名为 `netmind` 的数据库。
3. 执行初始化脚本：`psql -d netmind -U postgres -f AI文档/SQL/Init.sql`。
4. 如需从旧版本升级，按文件名顺序执行 `AI文档/SQL/P*.sql` 迁移脚本。

### 1.3 启动后端

```powershell
dotnet run --project src\NetMind.WebApi\NetMind.WebApi.csproj
```

后端默认监听 `http://localhost:5119`，开发环境下会自动尝试启动前端开发服务。

### 1.4 启动前端

```powershell
cd src\NetMind.Frontend
npm install
npm run dev
```

前端开发服务运行在 `http://localhost:5173`。

### 1.5 AI 模型配置

NetMind 支持两种 AI 模型来源：

- **DeepSeek Cloud（云模型）**：需要在「设置 → AI 大模型配置」中填写 API Key。
- **Ollama Local（本地模型）**：需要本机安装 Ollama 并拉取对应模型。

在应用内，点击顶部导航栏的"设置"按钮，你可以：
- 添加自定义 AI 模型（名称、API 地址、API Key，仅保存在浏览器本地）
- 调整 AI 对话上下文长度（1K~1M，推荐 50K）

## 2. 界面布局

NetMind 采用三栏布局：

| 区域 | 位置 | 功能 |
| --- | --- | --- |
| **侧边栏** | 左侧（280px） | 思维导图列表、新增导图入口、全局搜索 |
| **主工作区** | 中间（自适应） | 思维导图画布或节点列表 |
| **知识卡片** | 右侧（380px） | 节点详情、Markdown 内容、关联图谱、AI 对话 |

顶部导航栏提供：展示/工作台模式切换、图/列表视图切换、全局搜索、历史对话入口、设置。

---

## 3. 模式切换

### 3.1 展示模式 vs 工作台模式

点击顶部导航栏的模式切换按钮可以在两种模式间切换：

- **展示模式**：知识卡片显示节点预览（Markdown 内容 + 关联图谱），适合浏览和查看知识。
- **工作台模式**：知识卡片显示节点编辑表单，适合修改节点内容、添加关联。

### 3.2 图视图 vs 列表视图

- **图视图**：以 Canvas 思维导图形式展示节点。支持节点绘制、父子连线、关联虚线、滚轮缩放和节点选择。
- **列表视图**：以树形列表展示节点层级。支持折叠展开和节点选择。

## 4. 思维导图管理

### 4.1 创建思维导图

1. 点击侧边栏的"新增导图"按钮。
2. 进入新增导图页面，可以直接创建空白导图，也可以通过 AI 清洗或需求对话生成。
3. 在画布或列表中添加节点来构建知识结构。

### 4.2 AI 清洗

将自然语言文本转换为标准思维导图结构：

1. 在新增导图页面输入自然语言描述。
2. 点击"AI 清洗"，AI 会分析文本并生成结构化的节点和层级关系。
3. 预览结果后确认保存。

### 4.3 需求结构化

将不完善的需求通过 AI 对话拆解为标准结构：

1. 输入你的需求描述。
2. AI 会逐步询问澄清，最终生成结构化导图。
3. 确认后导入数据库。

### 4.4 导入导出

- **导出**：在侧边栏思维导图上点击导出，可以导出为 `.mindmap.json` 文件。
- **导入**：通过这些文件可以在不同实例间共享知识结构。

## 5. 节点操作

### 5.1 创建节点

- 在画布中右键点击已有节点选择添加子节点。
- 在列表视图中使用添加按钮。

### 5.2 编辑节点

1. 切换到工作台模式。
2. 点击画布或列表中的节点，知识卡片显示编辑表单。
3. 修改标题、内容（支持 Markdown 格式）、排序序号后保存。

### 5.3 知识卡片与 Markdown

知识卡片支持 Markdown 语法展示，包括：
- 标题层级（# ## ###）
- 列表（有序/无序）
- 粗体、斜体
- 代码块
- 引用块
- 表格

### 5.4 节点引用

在编辑节点内容时，输入 `[[` 可以打开全局搜索弹窗，选中目标节点后在光标位置插入引用链接。引用格式为 `[[标题|ID]]`，在展示模式下可点击跳转。

### 5.5 节点关联

- 在工作台模式的关联编辑区，可以为当前节点添加关联关系。
- 支持定义关系类型（如 `relates_to`、`depends_on` 等）和权重。
- 关联图谱显示当前节点的一层和二层关联。
- 跨图关联：可以在不同思维导图之间建立节点关联，点击可跳转到对应导图。

### 5.6 节点删除

- 删除节点时可以选择"仅删除当前节点"或"删除整棵子树"。
- 删除操作使用逻辑删除（软删除），数据可恢复。

## 6. AI 对话功能

### 6.1 AI 对话入口

知识卡片左侧有一个浮窗 AI 按钮，点击可展开 AI 对话面板。面板包含：

- **模式选择器**：支持节点问答 Agent、全图问答 Agent、全局问答 Agent 和应用帮助
- **上下文指示条**：显示当前对话上下文使用量（绿色→黄色→红色）
- **消息列表**：显示用户、AI、系统消息
- **输入区**：支持 Enter 发送、Shift+Enter 换行

### 6.2 AI Agent 模式

| 模式 | 说明 | 状态 |
| --- | --- | --- |
| **节点问答 Agent** | 节点聚焦的 Agent 模式，接收当前节点、父子节点、关联节点和对话历史，可执行 Tool 调用 | 已实现 |
| **全图问答 Agent** | 思维导图全局的 Agent 模式，接收当前导图全量节点和关联数据，可执行 Tool 调用 | 已实现 |
| **全局问答 Agent** | 不传递节点或思维导图数据，仅基于基础信息、对话历史和 Agent 记忆进行全局问答 | 已实现 |
| **应用帮助** | 回答关于 NetMind 软件本身的使用问题；正式说明书只读，学习经验追加到专门学习记录文档，由管理员统一维护说明书 | 已实现 |

### 6.3 上下文管理

AI 对话自动管理上下文长度，分为四级：

- **宽裕（0-60%）**：正常对话，无压缩。
- **压缩中（60-80%）**：AI 自动压缩历史上下文，同时限制回复长度。
- **紧张（80-100%）**：丢弃历史上下文，仅使用当前消息。
- **超限（>100%）**：拒绝请求，提示删减或分次发送。

上下文上限可在设置中配置（1K~1M，推荐 50K）。

## 9. 常见问题

**Q：AI 清洗/对话没有响应？**
A：请检查 AI 模型配置。如果使用 DeepSeek Cloud，确保已在设置页填写 API Key。如果使用 Ollama，确保本机 Ollama 服务已启动且模型已拉取。

**Q：无法连接数据库？**
A：检查 PostgreSQL 服务是否运行，并确认后端配置文件 `ConnectionStrings:Postgres` 是可用的完整连接字符串。

**Q：节点删除后能恢复吗？**
A：当前使用逻辑删除（软删除），数据在数据库中仍保留。如需物理删除，请联系管理员操作数据库。

**Q：如何分享思维导图？**
A：使用导出功能将思维导图导出为 `.mindmap.json` 文件，接收方使用导入功能即可加载。

**Q：Markdown 内容如何换行？**
A：标准 Markdown 语法：两个空格加回车，或空一行开始新段落。

## 10. 技术架构简述

| 层级 | 技术 |
| --- | --- |
| 后端 | .NET 8 Web API |
| 数据库 | PostgreSQL |
| 前端 | Vue 3 + Vite + Element Plus |
| AI | DeepSeek Cloud / Ollama Local，可通过配置切换 |

项目代码结构：
- `src/NetMind.WebApi` — HTTP API、依赖注入、日志、Swagger
- `src/NetMind.Services` — 业务编排、校验、导入导出、AI 调用
- `src/NetMind.Repository` — PostgreSQL 数据访问
- `src/NetMind.Models` — DTO、实体、ViewModel
- `src/NetMind.Frontend` — Vue3/Vite 前端项目

# NetMind 应用帮助 Agent 使用技巧

本文件用于维护应用帮助 Agent 可复用的 NetMind 使用技巧，让后续回答更稳定、更贴近真实操作。

维护规则：

- 只记录已由正式说明书、代码、稳定复现结果或管理员确认的技巧。
- 应用帮助 Agent 只能通过 `incremental_file_modifier` 对本文件做小范围增量维护，可补充、修正和合并同类技巧。
- 不记录一次性会话细节、未验证结论、密钥或用户隐私。
- 正式应用说明书仍由管理员维护，本文件不能替代正式说明书。
- 原始学习线索和待筛选经验仍追加到 `app-help-learning-log.md`。

## 总进度

当前项目已完成 P0 数据闭环 Demo、P1 基础结构化能力、P2 可用产品形态、P3 知识图谱化与产品补强和 P4 AI 普通聊天。P0 建立了 .NET WebAPI、Vue3 前端、PostgreSQL 表结构和导图/节点/关联的最小 CRUD 闭环。P1 在此基础上补齐完整导图导入导出、AI 清洗、真实模型配置、上下文需求澄清、中文本土化、接口日志、AI API 日志、存储层写操作日志和 AI 对话记录表。P2 将前端从 Demo 页面推进到可用产品形态，完成主工作台重构、Canvas 思维导图、图上编辑、知识卡片、关联图谱、响应式优化和节点排序校验。P3 完成敏感配置治理、Prompt 外置、节点链接式关联、跨图跳转、全局搜索、历史对话入口、节点坐标保存和删除导图链路完善。P4 完成 AI 普通聊天核心能力：设置页全局模型切换、前端自定义模型配置、节点级 AI 辅助对话（上下文分级管理）、六种模式对话框架（节点/全图/应用帮助已实现）、全图问答、Markdown 表格渲染和部署后 API Key 缺失修复。

## P1 阶段收尾摘要

P1 已从"手动维护导图"推进到"AI 生成标准结构，用户确认后进入导图数据层"。核心成果包括：`netmind.mindmap.v1` 导入导出结构、DeepSeek/Ollama 配置化调用、上下文压缩与需求澄清对话、AI 对话记录落库、前后端中文化、日志文件输出和接口/存储/AI 调用日志。当前限制是本地环境未完整覆盖真实 PostgreSQL 与外部模型冒烟，P2 前建议先执行 SQL 迁移并补一轮真实环境验证。

## P2 阶段收尾摘要

P2 已完成"可用产品形态"的主要目标。前端引入 Element Plus 并拆分为页面、组件、组合逻辑和 API 服务边界；主页面形成展示/工作台与图/列表两组视图模型；Canvas 思维导图支持节点绘制、父子连线、关联虚线、拖拽平移、滚轮缩放、节点拖动和工作台图上编辑；知识卡片支持 Markdown 展示，并内嵌两层关联图谱；新增导图页面集中承载 AI 清洗、需求对话和导入导出；后端更新节点时补充同级排序重复校验。

P2 收尾补齐根目录 `readme.md`、`AI文档/部署文档.md`，并更新项目结构速查。当前已知限制是项目健康检查展示数据曾停留在旧阶段，如后续需要对外展示真实阶段状态，应单独同步检查。

## P3 阶段收尾摘要

P3 定位为"知识图谱化与产品补强"，现已收尾完成。P3.0 完成项目敏感信息及 AI 配置优化：移除仓库配置中的 DeepSeek 明文 Key，改为通过 `DEEPSEEK_API_KEY` 环境变量读取；AI Prompt 迁移到中文 `.prompt.md` 文件，并由 `PromptFiles` 配置引用。P3.1/P3.2 完成节点链接式关联、跨图跳转、全局搜索、历史对话入口、节点坐标保存和删除导图链路完善。P3.3 完成收尾文档和仓库治理。

## P4 阶段收尾摘要

P4 定义为"AI 普通聊天"，聚焦于自然语言交互与导图内信息检索，不涉及自主决策或工具调用。核心成果如下：

- **P4.0 全局设置与体验优化**：前端设置弹窗（自定义模型、上下文长度）、知识卡片固定右侧面板、插入引用光标位置优化。
- **P4.1 节点级 AI 辅助对话**：`POST /api/ai/node-chat` 端点、上下文四级分级管理（宽裕/压缩/紧张/超限）、AI 聊天浮窗面板、上下文自动压缩。
- **P4.2 六种模式对话框架**：模式选择器（节点问答/全图问答/全局问答/应用帮助等）、应用帮助模式（加载说明书作为知识库）、对话历史记录持久化。
- **P4.3 全图问答与 Bug 修复**：全图问答聊天模式、历史记录错误提示优化、AI 命名（小节/全图/小助）、Markdown 表格渲染。
- **P4.4 全局模型切换与部署修复**：前端 Settings 全局默认模型选择（合并后端+自定义模型）、后端支持前端直传 endpoint/provider/apiKey（解决自定义模型无法识别问题）、API Key 缺失中文提示、CreateMapPage 移除模型选择器（改为全局统一管理）。

P4 已完成"AI 普通聊天"全部核心能力。下一阶段 P5 将进入"AI Agent 基础建设"：工具/函数调用接口、任务拆分与规划、记忆与上下文管理和意图识别。

## P5 阶段规划摘要

P5 定位为"AI Agent 基础建设"，聚焦于智能体的认知与执行底层骨架，与 P4 普通聊天形成清晰边界。核心能力包括：

- 工具/函数调用接口：让 AI 能执行外部操作（节点查询、导图读取、只读检索、受控写入）。
- 任务拆分与规划：将用户复杂指令分解为可执行的子步骤。
- 记忆与上下文管理：持久化状态跟踪，跨对话记忆。
- 意图识别与多轮任务执行：路由不同请求类型，支持多步任务。

打算用脚本实现与原应用隔离，仅交互与普通聊天有一定区别，尽可能与普通聊天保持一致

## P6 阶段规划摘要

P6 定位为"AI Agent 功能模块"，在 P5 基础建设之上构建具体业务应用。功能按上下文范围划分为四类：

| 功能模块 | 范围 | 权限策略 |
| --- | --- | --- |
| 节点聚焦辅助 | 当前节点、父子节点、直接关联节点 | 可生成编辑建议，写入前必须用户确认 |
| 思维导图全局辅助 | 当前导图全量结构与摘要 | 可生成批量整理方案，实际修改走受控工具 |
| 数据库全局只读问答 | 全库导图、节点、关联和语义检索结果 | 只读问答，不允许写入 |
| 软件操作问答 | 当前页面状态、帮助文档和接口能力 | 只读解释与操作指引，不读取无关业务数据 |

实施顺序建议从"数据库全局只读问答"和"软件操作问答"开始（权限风险最低），再进入节点聚焦辅助，最后做导图全局辅助和批量修改。

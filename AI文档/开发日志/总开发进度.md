## 总进度

当前项目已完成 P0 数据闭环 Demo、P1 基础结构化能力、P2 可用产品形态、P3 知识图谱化与产品补强、P4 AI 普通聊天和 P5 AI Agent 基础接入。P0 建立了 .NET WebAPI、Vue3 前端、PostgreSQL 表结构和导图/节点/关联的最小 CRUD 闭环。P1 在此基础上补齐完整导图导入导出、AI 清洗、真实模型配置、上下文需求澄清、中文本土化、接口日志、AI API 日志、存储层写操作日志和 AI 对话记录表。P2 将前端从 Demo 页面推进到可用产品形态，完成主工作台重构、Canvas 思维导图、图上编辑、知识卡片、关联图谱、响应式优化和节点排序校验。P3 完成敏感配置治理、Prompt 外置、节点链接式关联、跨图跳转、全局搜索、历史对话入口、节点坐标保存和删除导图链路完善。P4 完成 AI 普通聊天核心能力。P5 完成节点问答 Agent、全图问答 Agent、全局问答 Agent、应用帮助 Agent 和 Skill 权限确认链路，并将前端 AI 浮窗收束为 Agent 优先入口。

## P1 阶段收尾摘要

P1 已从"手动维护导图"推进到"AI 生成标准结构，用户确认后进入导图数据层"。核心成果包括：`netmind.mindmap.v1` 导入导出结构、DeepSeek/Ollama 配置化调用、上下文压缩与需求澄清对话、AI 对话记录落库、前后端中文化、日志文件输出和接口/存储/AI 调用日志。当前限制是本地环境未完整覆盖真实 PostgreSQL 与外部模型冒烟，P2 前建议先执行 SQL 迁移并补一轮真实环境验证。

## P2 阶段收尾摘要

P2 已完成"可用产品形态"的主要目标。前端引入 Element Plus 并拆分为页面、组件、组合逻辑和 API 服务边界；主页面形成展示/工作台与图/列表两组视图模型；Canvas 思维导图支持节点绘制、父子连线、关联虚线、拖拽平移、滚轮缩放、节点拖动和工作台图上编辑；知识卡片支持 Markdown 展示，并内嵌两层关联图谱；新增导图页面集中承载 AI 清洗、需求对话和导入导出；后端更新节点时补充同级排序重复校验。

P2 收尾补齐根目录 `readme.md`、`AI文档/部署文档.md`，并更新项目结构速查。当前已知限制是项目健康检查展示数据曾停留在旧阶段，如后续需要对外展示真实阶段状态，应单独同步检查。

## P3 阶段收尾摘要

P3 定位为"知识图谱化与产品补强"，现已收尾完成。P3.0 完成项目敏感信息及 AI 配置优化：移除仓库配置中的 DeepSeek 明文 Key，改为通过 `DEEPSEEK_API_KEY` 环境变量读取；AI Prompt 迁移到中文 `.prompt.md` 文件，并由 `PromptFiles` 配置引用。P3.1/P3.2 完成节点链接式关联、跨图跳转、全局搜索、历史对话入口、节点坐标保存和删除导图链路完善。P3.3 完成收尾文档和仓库治理。

## P4 阶段收尾摘要

P4 定义为"AI 普通聊天"，聚焦于自然语言交互与导图内信息检索，不涉及自主决策或工具调用。核心成果如下：

- **P4.0 全局设置与体验优化**：前端设置弹窗（自定义模型、上下文长度）、知识卡片固定右侧面板、插入引用光标位置优化。
- **P4.1 节点级 AI 辅助对话**：`POST /api/ai/node-chat` 端点、上下文四级分级管理（宽裕/压缩/紧张/超限）、AI 聊天浮窗面板、上下文自动压缩。
- **P4.2 六种模式对话框架**：模式选择器（节点问答/全图问答/全局问答/应用帮助等）、应用帮助模式（加载说明书作为知识库）、对话历史记录持久化。
- **P4.3 全图问答与 Bug 修复**：全图问答聊天模式、历史记录错误提示优化、AI 命名（小节/全图/小助）、Markdown 表格渲染。
- **P4.4 全局模型切换与部署修复**：前端 Settings 全局默认模型选择（合并后端+自定义模型）、后端支持前端直传 endpoint/provider/apiKey（解决自定义模型无法识别问题）、API Key 缺失中文提示、CreateMapPage 移除模型选择器（改为全局统一管理）。

P4 已完成"AI 普通聊天"全部核心能力。下一阶段 P5 将进入"AI Agent 基础建设"：工具/函数调用接口、任务拆分与规划、记忆与上下文管理和意图识别。

## P5 阶段规划摘要

P5 定位为"AI Agent 基础建设"，聚焦于智能体的认知与执行底层骨架，与 P4 普通聊天形成清晰边界。P5 当前已收尾完成，版本口径为 v1.6.0。核心成果包括：

- AgentBuild 调用层：后端通过子进程调用外部 `src.agent_kernel`，并统一传入模型、上下文、Skill Runtime 和权限确认记录。
- Agent 模式接入：前端保留节点问答 Agent、全图问答 Agent、全局问答 Agent 和应用帮助；删除节点问答/全图问答普通聊天入口。
- Skill 权限链路：前端支持 Skill 允许/拒绝与拒绝原因，后端归一化权限确认参数。
- 应用帮助 Agent：不再把说明书原文塞入请求上下文，只传入说明书只读绝对路径和学习记录绝对路径；Agent 在对话中持续学习，但只能追加学习记录，正式说明书由管理员统一维护。

Agent 由外部脚本实现，与原应用业务代码隔离；交互层尽可能保持与普通聊天一致，但能力边界转向可执行 Skill 的 Agent 模式。

### P5.0 节点问答 Agent 接入

P5.0 已完成六种聊天方式中的「节点问答（Agent）」第一版接入。后端新增 `IAiAgentService` / `AiAgentService`，通过子进程调用外部 AgentBuild `src.agent_kernel`，并将当前节点、父节点链、子节点、关联节点、对话历史、全局模型配置和 Skill 权限记录组装为 Agent Kernel 输入。前端设置页新增 AgentBuild 根目录配置，AI 浮窗启用「节点问答（Agent）」模式，支持展示 Agent 返回的 Skill 调用记录，并在 `waiting_permission` 时由用户允许或拒绝后继续下一轮。

当前边界：`domain_and_skill_binding` 固定使用 `default`；AgentBuild 真实模型调用要求 OpenAI-compatible Chat Completions 接口，暂不支持 Ollama `/api/chat`。

### P5.1 全图与全局问答 Agent 接入

P5.1 已完成「全图问答（Agent）」和「全局问答（Agent）」。后端新增 `POST /api/ai/map-agent-chat` 与 `POST /api/ai/global-agent-chat`，复用 P5.0 AgentBuild 调用层、模型配置转换、Skill 权限确认和 Agent 记忆机制。全图 Agent 会把当前导图基础信息、全量节点、节点内容、关联关系和统计信息传入 `focus_context`；全局 Agent 只传入 NetMind 基础信息、对话历史和上下文预算，不传递节点或思维导图数据。按 AgentBuild 当前接口规范，后端同步补充 `skill_runtime`，用于 Skill 执行时注入 NetMind WebAPI 地址、通用超时和 endpoint 映射；Agent 场景提示词已放入 `Config/AiCleanPrompts`，服务默认监听地址读取 `App:BaseUrl`。前端 AI 浮窗已启用两个模式，并复用既有 Skill 调用展示与确认交互。

当前边界：未进行真实外部模型端到端验证；若本机 `py` 启动器不可用，需要在后端配置中调整 `AiAgent:PythonExecutable`。

### P5.3 P5 收尾与后续规划

P5.3 完成 P5 收尾：前端 AI 浮窗删除「节点问答（聊天）」和「全图问答（聊天）」入口，剩余问答入口统一为 Agent；应用帮助改为 `app-help-agent`，只把说明书只读绝对路径和学习记录绝对路径交给 Agent，不再随请求携带说明书原文，并要求 Agent 只能增量追加学习记录，由管理员统一维护正式说明书。文档同步更新总开发进度、项目结构速查和部署文档，明确部署时必须接入 AgentBuild 脚本。

当前边界：普通聊天后端端点暂保留用于兼容历史接口和可能的调试；产品入口已收束为 Agent 模式。

## P6 / v1.7.0 阶段规划摘要

P6 是下一个大阶段，目标版本为 v1.7.0，主要补全 Agent SKILL，并对软件整体做稳定维护版完善。规划重点：

- Agent SKILL 补全：围绕节点读取、导图读取、全局只读检索、说明书维护、受控写入建议等场景补齐 Skill。
- 软件整体完善：修复已知体验问题，补齐错误提示、日志、验证脚本、文档和部署细节。
- 稳定维护版本：收敛功能入口，减少实验性分支能力，形成适合长期维护和小版本迭代的基线。
- 端到端验证：补充真实 AgentBuild、真实模型、数据库和前端交互链路验证。

功能按上下文范围划分为四类：

| 功能模块 | 范围 | 权限策略 |
| --- | --- | --- |
| 节点聚焦辅助 | 当前节点、父子节点、直接关联节点 | 可生成编辑建议，写入前必须用户确认 |
| 思维导图全局辅助 | 当前导图全量结构与摘要 | 可生成批量整理方案，实际修改走受控工具 |
| 数据库全局只读问答 | 全库导图、节点、关联和语义检索结果 | 只读问答，不允许写入 |
| 软件操作问答 | 当前页面状态、帮助文档和接口能力 | 只读解释与操作指引，不读取无关业务数据 |

实施顺序建议从"数据库全局只读问答"和"软件操作问答"开始（权限风险最低），再进入节点聚焦辅助，最后做导图全局辅助和批量修改。

## P7 / v2.0.0 阶段规划摘要

P7 是 v2.0.0 扩展化阶段，不再按商业化方向规划。重点从单机可用和稳定维护，推进到用户、安装包、社区、多端和生态扩展：

- 用户支持：用户体系、权限边界、个人配置和数据迁移策略。
- 安装包：更完整的 Windows 安装器、升级、卸载、启动脚本和 AgentBuild 依赖检查。
- 社区：说明书、贡献指南、问题反馈流程和可共享模板。
- 多端：桌面壳、局域网访问、未来移动端或轻客户端可行性。
- 扩展生态：Skill 插件化、模型提供方扩展、导入导出格式扩展。

# P5 开发日志

更新时间：2026-05-13

## P5.0 阶段

### 目标

实现六种聊天方式中的「节点问答（Agent）」，通过 NetMind 后端调用外部 AgentBuild AI Agent 内核脚本，并为后续其他 Agent 模式预留通用调用入口。

### 完成内容

1. **AgentBuild 通用调用层**
   - 新增 `IAiAgentService` / `AiAgentService`，统一负责 AgentBuild 根目录解析、Python 子进程调用、stdin/stdout JSON 交互、超时控制和日志记录。
   - 后端通过 `python -m src.agent_kernel` 等价方式调用 AgentBuild；默认 `PythonExecutable=py`，避免本机 `python` 不在 PATH 时无法运行。
   - 支持将 AgentBuild 返回的 `status`、`agent_target`、`main_text`、`skill_calls`、`context_update` 原样映射给前端。

2. **节点问答 Agent 后端端点**
   - 新增 `POST /api/ai/node-agent-chat`。
   - 请求包含当前节点 ID、用户消息、对话上下文、AgentBuild 路径、`confirmedSkillCalls`、`historySkillCalls` 和全局模型配置。
   - 后端加载当前节点、父节点链、子节点和关联节点，组装为 Agent Kernel 的 `focus_context`。
   - `domain_and_skill_binding` 当前固定使用 `default`。

3. **Agent 配置**
   - 新增 `AiAgentOptions`，配置项位于 `appsettings.json` / `appsettings.Development.json` 的 `AiAgent` 节点。
   - 节点问答 Agent 的 `IdentityLines` 和 `CuesLines` 写入配置文件，满足 Prompt 不硬编码要求。
   - 全局默认 AI 模型会转换为 AgentBuild 的 `model_config`，并由后端注入 API Key。

4. **前端节点 Agent 模式**
   - 设置弹窗新增「AgentBuild 脚本设置」，将 AgentBuild 根目录保存在 localStorage。
   - AI 浮窗启用「节点问答（Agent）」模式。
   - `useNodeAiChat.js` 新增 Agent 上下文、Skill 调用历史和权限确认状态管理。
   - 前端展示 Agent Skill 调用记录；当状态为 `waiting_permission` 时展示「允许 / 拒绝」按钮，并把确认结果带回后端继续执行。

5. **文档更新**
   - 更新 `AI大模型配置说明.md`，记录 AgentBuild 配置、端点、模型约束和权限交互。
   - 更新 `项目结构速查.md` 和 `总开发进度.md`。

6. **权限确认交互修复**
   - 修复 Agent Skill 权限确认后旧卡片仍保持可点击状态的问题。
   - 点击「允许 / 拒绝」后立即将本地 Skill 状态锁定为「已允许 / 已拒绝」，隐藏权限按钮，避免重复发送同一个确认请求。

# P3 开发日志

## 2026-05-07 P3.0 项目敏感信息及配置优化

### 本阶段目标

- 移除仓库配置中的 AI API 明文密钥。
- 将 AI Prompt 从 JSON 字符串数组迁移到更易读、易修改的中文文本配置文件。
- 保持现有模型配置和后端调用链路兼容。

### 完成内容

- 安全配置：
  - 移除 `src/NetMind.WebApi/appsettings.json` 和 `publish/netmind/appsettings.json` 中的 DeepSeek 明文 Key。
  - DeepSeek 模型统一通过 `ApiKeyEnvironmentVariable = DEEPSEEK_API_KEY` 读取密钥。
  - 配置备注明确仓库不保存明文 Key。
- Prompt 配置：
  - 新增 `src/NetMind.WebApi/Config/AiCleanPrompts/*.prompt.md`，包含系统约束、自然语言清洗、需求结构化、需求澄清对话和上下文压缩 5 类 Prompt。
  - 将主要 Prompt 翻译为中文，并减少 JSON 配置中的转义和引号噪音。
  - `appsettings*.json` 改为 `AiClean:Prompt:PromptFiles` 路径配置。
- 后端读取：
  - `Program.cs` 优先读取 Prompt 文件。
  - 保留旧 `SystemPromptLines` / `UserPromptTemplateLines` 等数组配置作为兼容路径。
  - WebApi 项目文件增加 Prompt 文件复制规则，构建输出包含 Prompt 配置。
- 文档：
  - 更新 `AI文档/项目/AI大模型配置说明.md`，记录新配置结构、Prompt 文件位置、密钥管理方式和运行要求。

#### 第二批：节点聚焦 AI 对话核心实现

6. **后端 API 端点**
   - 新增 `POST /api/ai/node-chat` 端点（`AiController.cs`）
   - 请求体 `AiNodeChatRequest`：包含 nodeId、message、context、modelId、apiKey、maxContextLength
   - 响应体 `AiNodeChatResult`：包含 reply（正文）、compressedContext（压缩上下文）、contextUsagePercent、contextStatus

7. **后端上下文分级管理**
   - 0-60%（宽裕 comfortable）：正常对话，无压缩
   - 60-80%（压缩 warning）：AI 压缩上下文至 40% 以下，回复正文不超过 40%，二者合计不超过 80%
   - 80-100%（紧张 critical）：丢弃上下文，仅传用户消息
   - >100%（超限 rejected）：直接拒绝，提示删减或分次发送
   - 百分比基于 `maxContextLength`（从 localStorage 读取，默认 51200）计算

8. **后端 AI 调用改造**
   - `AiCleanService` 构造函数新增 `INodeRepository` 和 `INodeRelationRepository` 依赖
   - 新增 `CallModelForTextAsync` / `CallOpenAiCompatibleTextAsync` / `CallOllamaTextAsync` —— 不强制 `json_object` 响应格式，支持自由文本返回
   - 原有 JSON 调用方法重构为 `CallModelAsync` 调用内部 `CallOpenAiCompatibleInternalAsync(jsonResponse: true)`
   - 新增 `ChatWithNodeAsync` 方法：加载节点上下文 → 分级判断 → 构建 Prompt → AI 调用 → 解析正文/压缩上下文

9. **后端 Prompt 文件**
   - `Config/AiCleanPrompts/node-chat.prompt.md`：基础提示词，要求按【正文】/【压缩上下文】结构输出
   - `Config/AiCleanPrompts/node-chat-compression.prompt.md`：压缩提示词，限制正文长度和压缩目标
   - `AiCleanOptions` 新增 `NodeChatPromptTemplateLines` 和 `NodeChatCompressionPromptTemplateLines`
   - `Program.cs` 和 `appsettings.json` / `appsettings.Development.json` 加载新 Prompt 文件

10. **后端节点上下文组装**
    - `BuildNodeContextAsync`：加载节点标题、内容、父节点链、子节点（前 10 个）、关联节点及关系方向
    - 通过 `INodeRepository.ListByMapAsync` 和 `INodeRelationRepository.ListByNodeAsync` 获取数据

11. **后端响应解析**
    - `ParseNodeChatResponse`：按【正文】/【压缩上下文】标记切分 AI 返回文本
    - 自动忽略空标记和"（空）"占位符
    - 验证正文非空

12. **前端浮窗 AI 聊天面板**（`NodeAiChatPanel.vue`）
    - 固定在知识卡片左侧外侧（`position: absolute; right: calc(100% + 8px)`）
    - 折叠态：显示 36×60px 竖排"AI"按钮（ChatDotRound 图标 + 文字）
    - 展开态：320px 宽度面板，含模式标签、上下文指示条、消息列表、输入区
    - 上下文指示条：彩色进度条（绿色→黄色→红色），显示百分比和标签
    - 消息列表：区分用户/AI/系统消息，不同背景色
    - 发送：支持 Enter 键发送，Shift+Enter 换行

13. **前端 AI 对话状态管理**（`useNodeAiChat.js`）
    - 管理 messages、inputText、loading、contextUsagePercent、compressedContext
    - `getContextText()`：优先使用压缩上下文，否则计算消息文本
    - 节点切换时自动清空对话
    - 从 localStorage 读取自定义模型的 API Key 传递到后端

14. **集成 KnowledgeCard**
    - `KnowledgeCard.vue` 导入 `NodeAiChatPanel`，包装在 `knowledge-card-wrapper`（position: relative）
    - 新增 props：`aiModels`、`selectedModelId`
    - `App.vue` 传递 `workspace.aiModels` 和 `workspace.selectedAiModelId`

15. **集成测试修复**
    - `NetMind.IntegrationTests/Program.cs` 新增 `StubNodeRepository` 和 `StubNodeRelationRepository` 实现
    - 适配 `AiCleanService` 新增的 repository 依赖

# P4 开发日志

更新时间：2026-05-09

## P4.0 阶段

### 目标
为节点及 AI 对话做基础及部分体验优化。

### 完成内容

1. **AI 大模型配置**
   - 前端新增设置弹窗（`SettingsDialog.vue`），支持配置自定义 AI 模型：名称、API 地址、API Key
   - API Key 仅保存在浏览器 localStorage，不提交到 Git 仓库
   - 后端 DTO（`AiDtos.cs`）新增 `ApiKey` 字段，支持前端传入自定义 API Key
   - `AiCleanService` 方法签名增加 `apiKeyOverride` 参数，优先使用请求传入的 Key
   - 修复 `ResolveApiKey` 中环境变量名使用 `model.ApiKeyEnvironmentVariable` 而非硬编码 `DEEPSEEK_API_KEY`

2. **AI 对话上下文设置**
   - 设置弹窗内添加上下文长度控制：滑块 + 数字输入框
   - 范围：最小值 1K（1024），推荐值 50K（51200），最大值 1M（1048576）
   - 当前为配置项，仅存 localStorage，尚未对接后端

3. **插入引用优化**
   - 新增 `useReferenceInsert.js` composable，支持在任意光标位置插入引用
   - 输入 `[[` 后打开搜索弹窗，选中节点后在原光标位置插入 `[[标题|ID]]`
   - 原来仅支持追加到文本末尾，现在支持任意位置插入

4. **知识卡片优化显示**
   - 移除 `NodePreviewDialog.vue` 弹窗组件
   - 新增 `KnowledgeCard.vue` 固定右侧面板
   - 布局统一为三栏：侧边栏(280px) | 画布/列表(1fr) | 知识卡片(380px)
   - 展示模式：知识卡片显示节点预览（Markdown 内容 + 关联图谱）
   - 工作台模式 - 图：知识卡片显示节点编辑表单
   - 工作台模式 - 列表：保持原有 `WorkbenchInspector`（含节点 CRUD 和关联管理）
   - 新增 CSS 类 `.layout.with-knowledge-card` 和响应式适配

5. **前端设置入口**
   - `AppHeader.vue` 新增"设置"按钮
   - `App.vue` 集成 `SettingsDialog`，通过 `@open-settings` 事件触发

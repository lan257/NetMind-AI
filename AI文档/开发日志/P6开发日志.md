更新时间：2026-05-21

## P6.0 阶段

### 目标

按新版 Agent Kernel 接口同步 NetMind 调用层。

### 完成内容

- Kernel 请求切到 API v2：`domain`、`tool_runtime`、`confirmed_tool_calls`、`history_tool_calls`。
- 响应读取 `tool_calls`，DTO 保留旧 Skill 字段兼容；前端改用 Tool 记录续跑和展示。
- Agent Prompt 改用 `tool_call_drafts`，补无数据库 Kernel 契约断言和配置说明。
- 修复同一轮返回多个待确认 Tool 时，前端确认一个 Tool 就提前续跑的问题；改为收齐本轮 Tool 权限决策后再调用下一轮 Kernel。

### 验证结果

- 后端 Release 构建通过，集成入口通过；数据库连接未配置，数据库段跳过。
- 前端生产构建通过，保留既有 Vite 大 chunk 提示。
- AgentBuild fake 模型最小 API v2 调用通过。

### 建议分支名

`codex/p6-0-agent-kernel-v2-adapter`

### Commit 规范

- `feat: 适配 Agent Kernel API v2 调用协议`
- `test: 补充 Agent Kernel v2 契约断言`
- `docs: 记录 P6.0 Agent 调用层适配`

### PR 说明

完成 AgentBuild v2 调用字段迁移、Tool runtime 注入与 ToolCall 前端兼容展示；影响后端 Agent 服务、前端权限确认、Agent Prompt 和 AI 配置文档；合并前关注真实 AgentBuild + 外部模型续跑链路。

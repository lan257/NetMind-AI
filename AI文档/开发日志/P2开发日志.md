# NetMind P2 开发日志

更新时间：2026-04-30

## 2026-04-30 P2.0 前端重构

### 本阶段目标

- 引入统一前端组件库，固化 Vue3 前端风格。
- 拆分原单文件 App.vue，形成页面、组件、组合逻辑和接口服务边界。
- 重构主页面为“展示/工作台 × 图/列表”的 2×2 思维导图界面模型。
- 迁出新增导图页面，集中承载 AI 清洗、需求对话、导入导出和空白导图创建。

### 完成内容

- 前端依赖：
  - 新增 `element-plus`。
  - 新增 `@element-plus/icons-vue`。
  - `main.js` 全局引入 Element Plus 和样式。
- 前端结构：
  - `App.vue` 缩减为页面编排和全局状态接线。
  - 新增 `src/services/api.js` 统一封装 API 请求和下载跳转。
  - 新增 `src/composables/useMindMapWorkspace.js` 承载导图、节点、AI、导入导出和对话状态。
  - 新增多个组件：顶部栏、悬浮消息、视图切换、导图列表、图占位画布、层级节点列表、工作台编辑卡片、节点预览弹窗和新增导图页面。
- 主页面：
  - 始终保留“展示/工作台”和“图/列表”两个切换控件。
  - 始终展示思维导图列表。
  - 新增思维导图按钮迁移为进入新增导图页面的入口，并放在导图列表附近。
  - 移除主页面上的导图标题输入框和原地新增按钮。
  - 展示模式不显示数据库编辑按钮。
  - 工作台模式仅在列表视图显示右侧节点编辑卡片。
  - 图视图右侧为占位画布。
  - 列表视图右侧为层级节点列表，支持折叠/展开。
  - 点击节点弹出只读内容弹窗，不提供编辑操作。
- 新增导图页面：
  - 承载空白导图创建、AI 清洗、需求对话、结构导入导出和文件导入导出。
  - 提供图/列表节点展示切换，图视图暂为占位画布。
- 交互提示：
  - 原页面流内消息改为顶部悬浮提示，避免挤占列表、画布和表单布局。
- 文档：
  - 更新 `AI文档/开发规范.md`，写入 Element Plus 使用规范、App.vue 拆分规范和悬浮消息规范。

### 验证结果

- 已执行 `npm run build`，通过。
- 构建存在 Element Plus 引入后的 chunk 体积警告，不影响本次功能构建结果。
- 依赖安装过程中首次遇到 Windows `EPERM spawn`，已用 `--ignore-scripts` 重新安装成功；Element Plus 当前构建验证通过。
- `npm audit` 提示 2 个 moderate 级别依赖告警，本阶段未执行破坏性升级。

### 已知问题

- 图视图当前按 P2.0 要求为占位画布，尚未接入真实可视化导图库。
- 新增导图页面的图/列表切换复用当前选中导图数据，导入或创建成功后会刷新并选中新导图。
- 工作台保留节点新增、保存、删除和删除子树能力，但不再提供导图删除和关联编辑入口。

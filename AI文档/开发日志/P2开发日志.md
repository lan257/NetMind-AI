## 2026-04-30 P2.1 思维导图 Canvas 画布

### 本阶段目标

- 将图视图从占位画布升级为可绘制节点关系的 Canvas 思维导图。
- 复用现有导图和节点数据，不新增后端接口和第三方可视化依赖。

### 完成内容

- 新增 `src/components/MindMapCanvas.vue`：
  - 使用 HTML Canvas 绘制思维导图。
  - 以导图标题作为中央根节点。
  - 根据节点 `parentId`、`orderNo` 和 `id` 构建父子树。
  - 顶层节点左右分布，子节点按层级向外展开。
  - 绘制高清网格背景、圆角节点、中心根节点、父子曲线连线和选中态。
  - 支持窗口尺寸变化后自动重绘，兼容高 DPI 屏幕。
  - 支持点击节点，展示模式打开只读预览，工作台模式仅选中节点。
- 主页面图视图接入 `MindMapCanvas`，替换原 `MapCanvasPlaceholder`。
- 新增导图页面的节点展示图视图同步接入 `MindMapCanvas`。
- 删除旧的占位画布组件和对应占位样式。

### 验证结果

- 首次执行 `npm run build` 被 PowerShell 执行策略拦截 `npm.ps1`。
- 改用 `npm.cmd run build` 后，沙箱内遇到 esbuild `spawn EPERM`。
- 经用户授权在沙箱外执行 `npm.cmd run build`，构建通过。
- 仍存在 Element Plus 引入后的 chunk 体积警告，不影响本次构建结果。

### 补充修复

- 修复 Canvas 画布持续向下延展问题：
  - 原因是绘制时读取带边框的 `getBoundingClientRect()` 高度后再写回 Canvas 样式高度，子元素和父容器之间形成 ResizeObserver 重绘反馈。
  - 改为使用画布容器的 `clientWidth/clientHeight` 设置绘制缓冲区，并由 CSS 固定容器高度。
- 已重新执行 `npm.cmd run build`，通过；仍存在既有 chunk 体积警告。

## 2026-05-06 P2.3 后端接口优化

### 本阶段目标

- 更新节点时校验同一导图、同一父节点下是否已有其他节点使用相同同级排序。

### 完成内容

- `INodeRepository` / `NodeRepository` 新增同级排序重复查询，排除当前被更新节点，并兼容根节点 `parent_id IS NULL` 的同级判断。
- `NodeService.UpdateAsync` 在更新节点前读取当前节点，若目标父节点下已有其他节点使用相同 `orderNo`，返回业务错误。
- `NodesController.UpdateAsync` 将节点更新业务校验错误统一返回 400，便于前端直接展示错误信息。

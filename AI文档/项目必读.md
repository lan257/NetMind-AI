# NetMind 项目必读目录

更新时间：2026-04-29


## 1. 项目概要

NetMind 是一个基于 AI 的知识网络构建与可视化工具，目标是把用户输入的文本、文档或需求清洗为标准结构，并以思维导图/知识图谱形式存储、展示和编辑。

## 2. 文档用途速查

| 文档 | 用途 |
| --- | --- |
| `AI文档/项目必读.md` | 项目入口目录。 |
| `AI文档/项目/项目结构速查.md` | 代码定位、接口定位 |
| `AI文档/开发日志/` | 开发过程完整记录 |
| `AI文档/项目/项目研发说明.md` | 产品流程、数据库结构参考、P0-P6 阶段规划。 |
| `AI文档/项目/项目基础说明.md` | 项目背景、目标、核心功能、用户、商业模式、MVP。 |
| `AI文档/项目/AI大模型配置说明.md` | AI 模型配置、Prompt 规范、DeepSeek/Ollama、环境变量。 |
| `AI文档/开发规范.md` | .NET 分层、命名、接口、配置、AI编程等要求。 |

## 3. 子目录用途

| 目录 | 用途 |
| --- | --- |
| `AI文档/项目/` | 项目相关文档，新增文档默认放在这里，按需查看 |
| `AI文档/开发日志/` | 项目开发日志，每次开发完成必须对最新阶段文档进行更新，按需查看 |
| `AI文档/SQL/` | 数据库初始化和迁移脚本。数据库结构发生改变必须新增安全可反复执行的SQL脚本 |
| `AI文档/Smoke/` | 各阶段冒烟验证脚本。 |
| `AI文档/.obsidian/` | Obsidian 本地配置，一般不用看。 |

## 4. 必须遵守的规范

1. AI编写代码均需写入开发日志，并在子阶段结束后生成git提交分支名、commit 规范、PR 说明推荐，无需提交。允许子阶段内进行编辑原有内容，禁止跨子阶段进行修改；
2. AI提示词必须写在配置文件内，其他可自行设计。
3. AI 配置或 Prompt 变化后，更新 `AI大模型配置说明.md`。
4. 项目必读.md,项目基础说明.md,项目研发说明.md，NET开发规范.md不允许擅自修改，只有用户连续重复三次才允许修改。
5. 开发时每一个大阶段写一个日志。
6. 只有该文档是必读的和开发规范.md是AI必读的，其余文件自行判断。

# NetMind 部署文档

更新时间：2026-05-14

## 1. 概述

NetMind 采用「单体 Web API + 静态前端」架构。部署流程为：

1. 构建前端（Vite）→ 产出 `dist/`
2. 发布后端（.NET 8 自包含）→ 产出 `publish/netmind/`
3. 确认 `publish/agent/` 脚本目录（安装包会放到软件根目录 `agent/`）
4. 组装前后端目录和 Agent 配置
5. 使用 Inno Setup 打包为 Windows 安装包（`.exe`）
6. 用户运行安装包，按需编辑本机配置文件或在设置页填写 AI Key 即可完成部署

推荐自包含发布（`--self-contained true`），目标机器无需安装 .NET Runtime。

## 2. 环境要求

### 2.1 构建环境

| 项目 | 要求 |
|------|------|
| .NET SDK | .NET 8.0 |
| Node.js | 18+（可运行 Vite 5） |
| Inno Setup | 6.x（含中文语言包） |

### 2.2 目标运行环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10+ / Windows Server 2016+ (x64) |
| .NET Runtime | 无需安装（自包含发布） |
| 数据库 | PostgreSQL 12+ |
| 网络 | 若使用云 AI 模型，需能访问 `api.deepseek.com` |
| Agent | 安装后位于软件根目录 `agent\src\agent_kernel.py`；也可在设置页切换到外部 AgentBuild 目录 |

## 3. 构建发布包

以下命令在项目根目录执行。

### 3.1 构建前端

```powershell
cd src\NetMind.Frontend
npm install
npm run build
cd ..\..
```

产物输出到 `src\NetMind.Frontend\dist`。

### 3.2 发布后端（自包含 win-x64）

```powershell
dotnet publish src\NetMind.WebApi\NetMind.WebApi.csproj -c Release -r win-x64 --self-contained true -o publish\netmind
```

产物输出到 `publish\netmind`，包含 `NetMind.WebApi.exe` 及所有依赖。

### 3.3 组装发布目录

后端在非 Development 环境下从可执行文件所在目录的上级查找前端静态文件，路径为 `../NetMind.Frontend/dist`。因此需要保持以下目录结构：

```text
publish/
├── netmind/                   ← 后端（ContentRoot）
│   ├── NetMind.WebApi.exe
│   ├── appsettings.json
│   ├── Config/
│   └── ...
└── NetMind.Frontend/
    └── dist/                  ← 前端构建产物
        ├── index.html
        └── assets/
```

组装命令：

```powershell
# 确保前端 dist 存在于 publish/NetMind.Frontend/dist
New-Item -ItemType Directory -Force publish\NetMind.Frontend | Out-Null
Copy-Item -Recurse -Force src\NetMind.Frontend\dist publish\NetMind.Frontend\dist
```

### 3.4 准备 Agent 脚本

P6.2 后，AI 浮窗中的节点问答、全图问答、全局问答和应用帮助默认通过发布包中的 `publish/agent/src/agent_kernel.py` 执行。该 Agent 文件夹由发布包提供，安装包会安装到软件根目录 `agent/`，Docker 镜像会复制到 `/agent`。

最小要求：

```text
agent/
└── src/
    └── agent_kernel.py
```

配置位置：

- 后端配置：`appsettings.json` → `AiAgent.AgentBuildPath`，默认 `../agent`
- 前端设置：设置弹窗 →「AgentBuild 脚本设置」

生产部署默认把 Agent 脚本放在安装目录旁边，例如：

```text
C:\Program Files\NetMind\
├── netmind\
├── NetMind.Frontend\
└── agent\
    └── src\agent_kernel.py
```

如果用户需要替换为外部 AgentBuild，可在设置页填写外部根目录。

### 3.5 Docker 镜像

`Dockerfile` 会将 `publish/agent/` 目录复制到镜像 `/agent`，并在运行镜像中安装 `python3`。后端配置 `AiAgent.AgentBuildPath=../agent` 在容器内会解析为 `/agent`，与安装包路径保持兼容。数据库连接建议通过挂载/覆盖 `appsettings.Local.json` 提供 `ConnectionStrings:Postgres`。

## 4. Inno Setup 打包

### 4.1 安装 Inno Setup

1. 下载 Inno Setup 6：https://jrsoftware.org/isdl.php
2. 安装时勾选中文语言包（Chinese Simplified）
3. 安装 Inno Script Studio（可选，方便编辑脚本）：https://www.kymoto.org/products/inno-script-studio

### 4.2 脚本说明

安装脚本位于项目根目录 `build.iss`，主要功能：

- 安装后端 `publish/netmind/` → `{app}/netmind/`
- 安装前端 `publish/NetMind.Frontend/dist/` → `{app}/NetMind.Frontend/dist/`
- 安装 `publish/agent/` 脚本目录 → `{app}/agent/`
- 附带 `publish/SQL/` 中的初始化/迁移脚本 → `{app}/SQL/`
- 安装向导不再要求填写运行环境变量
- `AiAgent.AgentBuildPath` 默认指向安装目录下的 `agent/`
- 自动将日志目录指向 `%ProgramData%\NetMind\Logs`
- 创建桌面快捷方式和开始菜单项

### 4.3 编译安装包

#### 方式一：Inno Setup 编译器 GUI

1. 启动 Inno Setup Compiler
2. 打开 `build.iss`
3. 点击 Build → Compile（或按 Ctrl+F9）
4. 安装包输出到 `artifacts\installer\`

#### 方式二：命令行

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" build.iss
```

### 4.4 版本号

安装包版本号在脚本顶部 `#define MyAppVersion` 定义。每次发布前更新此值。

## 5. 安装与配置

### 5.1 运行安装包

双击 `NetMind-Setup-x.x.x.exe`，按向导操作：

1. 选择安装目录（默认 `C:\Program Files\NetMind`）
2. 确认安装内容
3. 确认安装

### 5.2 运行配置

安装向导不再要求填写 `PGSTR` 或 `DEEPSEEK_API_KEY`。运行配置改为文件配置和应用设置：

| 配置 | 说明 | 位置 |
|------|------|------|
| PostgreSQL 连接字符串 | 完整 PostgreSQL 连接字符串 | `{安装目录}\netmind\appsettings.Local.json` 的 `ConnectionStrings:Postgres` |
| DeepSeek API Key | 云模型 API Key | 应用顶部「设置」→「AI 大模型配置」 |
| Agent 脚本目录 | 默认内置脚本目录 | `{安装目录}\agent`，可在设置页改为外部 AgentBuild |

`appsettings.Local.json` 不随仓库提交，只用于保存本机 PostgreSQL 连接串。

### 5.3 安装后手动配置

#### 本机配置文件

在 `{安装目录}\netmind\appsettings.Local.json` 中填写：

```json
{
  "ConnectionStrings": {
    "Postgres": "Host=127.0.0.1;Port=5432;Database=netmind;Username=postgres;Password=your_password;"
  },
  "AiClean": {
    "Models": [
      {
        "Id": "deepseek-cloud",
        "ApiKey": "your_api_key"
      }
    ]
  }
}
```

API Key 只在应用设置页填写。设置页中的 API Key 在发送给后端前会先加密。

创建 `run.bat` 放在安装目录下：

```bat
@echo off
set ASPNETCORE_ENVIRONMENT=Production
cd /d "%~dp0netmind"
start http://localhost:5120
NetMind.WebApi.exe
```

#### Ollama 本地模型（可选）

如需使用本地 Ollama 模型，确保 Ollama 服务已安装并运行，然后在 `appsettings.json` 的 `AiClean.Models` 中调整 `ollama-local` 的 `Endpoint` 和 `Model`。

#### AgentBuild 脚本配置

编辑 `{安装目录}\netmind\appsettings.json`，确认 `AiAgent.AgentBuildPath` 指向 AgentBuild 根目录：

```json
"AiAgent": {
  "AgentBuildPath": "../agent",
  "PythonExecutable": "py"
}
```

该目录必须包含 `src\agent_kernel.py`。安装包默认已安装到 `{安装目录}\agent`。如果用户把 AgentBuild 放在其他位置，也可以在应用设置页「AgentBuild 脚本设置」中填写绝对路径。未配置或路径错误时，节点问答 Agent、全图问答 Agent、全局问答 Agent 和应用帮助都会返回路径错误提示。

应用帮助 Agent 不再随请求携带说明书原文，只会把说明书文件绝对路径、学习记录文件绝对路径和使用技巧文件绝对路径传给 Agent。部署时请确保 `{安装目录}\netmind\Config\AiCleanPrompts\directions-help.prompt.md` 存在且运行账号具备读取权限；正式说明书不应授予 Agent 写入权限。学习经验统一追加到 `{安装目录}\netmind\Config\AiCleanPrompts\app-help-learning-log.md`，稳定技巧通过 `incremental_file_modifier` 增量维护到 `{安装目录}\netmind\Config\AiCleanPrompts\app-help-usage-tips.md`；如需让 Agent 自我优化，只给学习记录和使用技巧文件写入权限。

#### 监听端口

生产环境默认监听 `http://0.0.0.0:5120`（开发环境为 `5119`）。可通过环境变量覆盖：

```powershell
$env:ASPNETCORE_URLS="http://0.0.0.0:8080"
```

## 6. 数据库初始化

安装完成后，首次使用前需初始化数据库：

1. 确保 PostgreSQL 服务运行
2. 创建数据库 `netmind`（如果尚未创建）：

```sql
CREATE DATABASE netmind;
```

3. 执行初始化脚本（使用 psql 或 pgAdmin）：

```powershell
# 使用 psql
psql -h localhost -p 5432 -U postgres -d netmind -f "C:\Program Files\NetMind\SQL\Init.sql"
```

4. 按文件名字母顺序执行迁移脚本：

```powershell
psql -h localhost -p 5432 -U postgres -d netmind -f "C:\Program Files\NetMind\SQL\P0.3_AddLogicalDelete.sql"
psql -h localhost -p 5432 -U postgres -d netmind -f "C:\Program Files\NetMind\SQL\P1.4_AddAiConversationRecord.sql"
psql -h localhost -p 5432 -U postgres -d netmind -f "C:\Program Files\NetMind\SQL\P3.2_AddNodeMetaLogicalDelete.sql"
psql -h localhost -p 5432 -U postgres -d netmind -f "C:\Program Files\NetMind\SQL\P3.2_AddNodePosition.sql"
```

> 迁移脚本保持可重复执行（幂等），按需执行即可。

## 7. 启动与运行

### 7.1 桌面快捷方式启动

双击桌面的「NetMind」快捷方式即可启动。应用会在后台控制台窗口中运行。

### 7.2 手动启动

```powershell
cd "C:\Program Files\NetMind\netmind"
$env:ASPNETCORE_ENVIRONMENT="Production"
.\NetMind.WebApi.exe
```

### 7.3 访问

- 应用首页：`http://localhost:5120`
- 接口文档：`http://localhost:5120/swagger`

## 8. 验证

启动服务后验证以下项目：

### 8.1 接口验证

```text
GET http://localhost:5120/api/system/health
GET http://localhost:5120/api/mind-maps
GET http://localhost:5120/swagger
```

### 8.2 前端验证

打开 `http://localhost:5120` 后确认：

- 首页正常加载（非空白）
- 思维导图列表可加载
- 图/列表视图可切换
- 工作台模式下可新增、编辑、删除节点
- 知识卡片可打开，显示 Markdown 内容和关联图谱
- 新增思维导图页面可执行 AI 清洗、需求对话、导入和导出
- 设置页已配置 AgentBuild 路径，AI 浮窗的节点问答 Agent、全图问答 Agent、全局问答 Agent 和应用帮助可正常启动

### 8.3 常见验证失败

| 现象 | 排查 |
|------|------|
| 首页空白或 404 | 确认 `npm run build` 已执行，`publish/NetMind.Frontend/dist` 存在且安装到位 |
| 数据库请求失败 | 检查 PostgreSQL 服务状态、连接字符串、数据库是否已创建、Init.sql 是否已执行 |
| AI 清洗失败 | 检查设置页 API Key、网络连通性、模型 Enable 状态 |
| AI Agent 模式提示 AgentBuild 路径错误 | 检查 `AiAgent.AgentBuildPath` 或设置页 AgentBuild 路径，确认目录内存在 `src\agent_kernel.py` |
| 应用帮助无法维护帮助经验 | 检查 `Config\AiCleanPrompts\app-help-learning-log.md` 和 `Config\AiCleanPrompts\app-help-usage-tips.md` 是否存在，以及运行账号是否有写入权限；正式说明书 `directions-help.prompt.md` 只需要读取权限 |
| 端口被占用 | 更换端口：`$env:ASPNETCORE_URLS="http://0.0.0.0:5118"` |

## 9. 日志

应用日志写入 `%ProgramData%\NetMind\Logs\`，文件名格式为 `netmind-yyyyMMdd.log`。

可通过 `appsettings.json` 的 `AppLogging` 节点调整日志配置：

```json
"AppLogging": {
  "FileEnabled": true,
  "Directory": "C:\\ProgramData\\NetMind\\Logs"
}
```

## 10. 升级与卸载

### 10.1 升级

1. 按第 3 节重新构建发布包
2. 更新 `build.iss` 中的 `MyAppVersion`
3. 重新编译安装包
4. 运行新安装包，覆盖安装到原目录
5. 安装完成后确认 `appsettings.Local.json` 和设置页中的模型配置
6. 按需执行新增的 SQL 迁移脚本

> 升级不会删除 `appsettings.json` 之外的用户数据。数据库数据不受影响。

### 10.2 卸载

- 通过 Windows 设置 → 应用 → NetMind → 卸载
- 或运行开始菜单中的「卸载 NetMind」

> 卸载不会删除 `%ProgramData%\NetMind\Logs\` 和 PostgreSQL 数据库，如需清理请手动删除。

## 11. 目录结构（安装后）

```text
C:\Program Files\NetMind\
├── netmind\                       ← 后端运行目录
│   ├── NetMind.WebApi.exe
│   ├── appsettings.json           ← 配置文件（安装后可手动修改）
│   ├── Config\
│   │   └── AiCleanPrompts\        ← AI Prompt 模板
│   └── ...
├── NetMind.Frontend\
│   └── dist\                      ← 前端静态文件
│       ├── index.html
│       └── assets\
├── agent\                         ← 内置 Agent 脚本目录（需包含 src\agent_kernel.py）
│   └── src\
│       └── agent_kernel.py
└── SQL\                           ← 数据库脚本（参考用）
    ├── Init.sql
    └── P*.sql

C:\ProgramData\NetMind\
└── Logs\                          ← 应用日志
    └── netmind-yyyyMMdd.log
```

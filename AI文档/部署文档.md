# NetMind 部署文档

更新时间：2026-05-06

## 1. 部署目标

NetMind 当前按单体 Web API + 静态前端方式部署：先构建 Vue 前端到 `src/NetMind.Frontend/dist`，再发布并运行 `NetMind.WebApi`。非 Development 环境下，后端会托管前端构建产物，并提供 API 与 Swagger 页面。

## 2. 环境要求

| 项目 | 要求 |
| --- | --- |
| .NET | .NET 8 SDK 或运行时 |
| Node.js | 可运行 Vite 5 构建的 Node.js 环境 |
| 数据库 | PostgreSQL |
| AI 云模型 | DeepSeek API Key，可选 |
| 本地模型 | Ollama 服务和配置模型，可选 |

## 3. 配置项

### 3.1 数据库

配置入口：

- `src/NetMind.WebApi/appsettings.json`
- `src/NetMind.WebApi/appsettings.Development.json`
- 环境变量或部署平台配置

连接字符串键名：

```text
ConnectionStrings__Postgres
```

本地默认值：

```text
Host=localhost;Port=5432;Database=netmind;Username=postgres;Password=admin;
```

生产环境应改为部署环境的真实数据库地址、账号和密码。

### 3.2 AI 模型

配置入口：

- `src/NetMind.WebApi/appsettings.json` 的 `AiClean` 节点。
- `AI文档/项目/AI大模型配置说明.md` 记录配置说明。

建议生产环境不要把真实 API Key 写入仓库文件，优先使用环境变量或部署平台密钥管理。DeepSeek 云模型需要可访问外网；Ollama 本地模型需要服务端能访问配置的 `Endpoint`。

### 3.3 监听地址

应用默认监听：

```text
http://0.0.0.0:5119
http://[::]:5119
```

也可以通过 `ASPNETCORE_URLS` 覆盖，例如：

```powershell
$env:ASPNETCORE_URLS="http://0.0.0.0:5119"
```

## 4. 数据库初始化

1. 创建 PostgreSQL 数据库，例如 `netmind`。
2. 执行初始化脚本：

```text
AI文档/SQL/Init.sql
```

3. 如从旧版本升级，按文件名阶段顺序执行迁移脚本：

```text
AI文档/SQL/P0.3_AddLogicalDelete.sql
AI文档/SQL/P1.4_AddAiConversationRecord.sql
```

迁移脚本应保持可重复执行；后续表结构变更继续放入 `AI文档/SQL/`。

## 5. 构建

### 5.1 还原后端依赖

```powershell
dotnet restore src\NetMind.sln --configfile src\NuGet.Config
```

### 5.2 安装并构建前端

```powershell
cd src\NetMind.Frontend
npm install
npm run build
cd ..\..
```

前端产物输出到：

```text
src/NetMind.Frontend/dist
```

### 5.3 发布后端

```powershell
dotnet publish src\NetMind.WebApi\NetMind.WebApi.csproj -c Release -o publish\netmind
```

发布前需要确保 `src/NetMind.Frontend/dist` 已存在。当前 Web API 在非 Development 环境下会从应用运行目录的上一级查找 `NetMind.Frontend/dist`。按上面的发布目录运行时，需要把前端产物复制到：

```text
publish/NetMind.Frontend/dist
```

示例：

```powershell
New-Item -ItemType Directory -Force publish\NetMind.Frontend | Out-Null
Copy-Item -Recurse -Force src\NetMind.Frontend\dist publish\NetMind.Frontend\dist
```

最终目录形态：

```text
publish/
  netmind/
    NetMind.WebApi.dll
  NetMind.Frontend/
    dist/
      index.html
      assets/
```

如部署目录结构发生变化，需要同步调整静态文件路径或部署时保持上述前后端相对目录结构。

## 6. 运行

示例：

```powershell
$env:ASPNETCORE_ENVIRONMENT="Production"
$env:ASPNETCORE_URLS="http://0.0.0.0:5119"
$env:ConnectionStrings__Postgres="Host=127.0.0.1;Port=5432;Database=netmind;Username=postgres;Password=your_password;"
dotnet publish\netmind\NetMind.WebApi.dll
```

访问地址：

```text
http://服务器地址:5119
```

接口文档：

```text
http://服务器地址:5119/swagger
```

## 7. 验证

### 7.1 构建验证

```powershell
dotnet build src\NetMind.sln -c Release --no-restore -v minimal
npm run build --prefix src\NetMind.Frontend
```

### 7.2 接口验证

启动服务后访问：

```text
GET /api/system/health
GET /api/mind-maps
GET /swagger
```

### 7.3 前端验证

打开首页后确认：

- 思维导图列表可加载。
- 图/列表视图可切换。
- 工作台模式可新增、编辑、删除节点。
- 知识卡片可打开，并显示 Markdown 内容和关联图谱。
- 新增思维导图页面可执行 AI 清洗、需求对话、导入和导出。

## 8. 日志

应用日志默认写入：

```text
src/NetMind.WebApi/Logs/netmind-yyyyMMdd.log
```

部署后路径取决于应用运行目录和 `AppLogging:Directory` 配置。

## 9. 常见问题

| 问题 | 处理 |
| --- | --- |
| 数据库请求失败 | 检查 PostgreSQL 服务、库名、账号密码、连接字符串和 SQL 初始化脚本是否已执行。 |
| 首页空白或静态资源 404 | 确认已执行 `npm run build`，且 `src/NetMind.Frontend/dist` 存在并随部署目录一起发布。 |
| AI 清洗失败 | 检查模型是否启用、Endpoint 是否可访问、API Key 是否正确、Ollama 模型是否已拉取并启动。 |
| Swagger 可访问但前端不可访问 | 检查运行环境是否为非 Development，以及静态前端目录相对路径是否符合当前代码读取逻辑。 |

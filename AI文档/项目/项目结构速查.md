## 1. 代码定位总览

### 1.1 根目录

| 路径 | 用途 |
| --- | --- |
| `AI文档/` | 项目说明、研发说明、开发日志、AI 配置说明、SQL 和冒烟脚本。 |
| `readme.md` | 仓库入口说明：项目简介、技术栈、本地启动、构建验证和文档入口。 |
| `AI文档/部署文档.md` | 部署说明：环境要求、配置项、数据库初始化、构建发布、运行验证和常见问题。 |
| `src/NetMind.sln` | .NET 解决方案入口。 |
| `src/Directory.Build.props` | C# 公共编译配置：`latest`、Nullable、ImplicitUsings。 |
| `src/NuGet.Config` | NuGet 包源配置。 |
| `src/NetMind.Frontend/` | Vue3/Vite 前端项目。 |

### 1.2 后端分层

| 项目 | 职责 | 重点文件 |
| --- | --- | --- |
| `NetMind.WebApi` | HTTP API、依赖注入、接口调用日志切面、全局异常包装、Swagger、静态前端托管。 | `Program.cs`、`Controllers/*.cs`、`Middleware/*.cs`、`Infrastructure/*.cs`、`Swagger/SwaggerDocumentFactory.cs`、`appsettings*.json` |
| `NetMind.Services` | 业务编排、校验、导入导出、AI 清洗调用。 | `Interfaces/*.cs`、`Implementations/*.cs`、`Configurations/AiCleanOptions.cs` |
| `NetMind.Repository` | PostgreSQL 数据访问。 | `Implementations/*Repository.cs`、`PostgresConnectionFactory.cs`、`Interfaces/*.cs` |
| `NetMind.Models` | DTO、实体、ViewModel。 | `Dtos/*.cs`、`Entities/*.cs`、`ViewModels/*.cs` |
| `NetMind.Common` | 通用响应包装、跨层日志接口。 | `Responses/ApiResult.cs`、`Logging/*.cs` |
| `NetMind.IntegrationTests` | 无第三方测试框架的集成验证入口。 | `Program.cs` |

## 2. 按功能快速找代码

### 2.1 系统启动、配置、公共能力

| 目标 | 入口文件 | 说明 |
| --- | --- | --- |
| 后端启动和依赖注入 | `src/NetMind.WebApi/Program.cs` | 注册 Controller、Repository、Service、AI HttpClient、AI 配置、日志实现。 |
| 接口调用日志切面 | `src/NetMind.WebApi/Middleware/ApiCallLoggingMiddleware.cs` | 记录方法、路径、Query、请求体、响应体、状态码、开始/结束时间和耗时，正文超长截断。 |
| 本地日志文件 | `src/NetMind.WebApi/Infrastructure/AppLogger.cs` | 同时写 ASP.NET Core 日志管道和 `src/NetMind.WebApi/Logs/netmind-yyyyMMdd.log`。 |
| 日志抽象 | `src/NetMind.Common/Logging/IAppLogger.cs` | 跨 WebApi、Services、Repository 复用的日志接口。 |
| 全局异常 JSON 包装 | `src/NetMind.WebApi/Program.cs` | 未捕获异常统一包装为 `ApiResult.Fail(...)`。 |
| 前端生产静态托管 | `src/NetMind.WebApi/Program.cs` | 非 Development 环境托管 `NetMind.Frontend/dist`。 |
| Development 自动启动前端 | `src/NetMind.WebApi/Program.cs` | 检查 5173 端口并尝试运行 `npm run dev`。 |
| 标准接口响应 | `src/NetMind.Common/Responses/ApiResult.cs` | API 成功/失败响应外壳。 |
| 项目状态/健康检查数据 | `src/NetMind.Repository/Implementations/ProjectStatusRepository.cs` | 健康检查展示数据入口；当前代码值仍为 `P1.4`，后续阶段如需对外展示 P2/P3 状态应同步更新。 |

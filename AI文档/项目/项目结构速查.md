### 1.4 发布与安装包速查

| 目标 | 推荐入口 | 说明 |
| --- | --- | --- |
| 前端生产构建 | `npm run build --prefix src/NetMind.Frontend` | 输出到 `src/NetMind.Frontend/dist`，由后端在非 Development 环境托管。 |
| 后端发布 | `dotnet publish src/NetMind.WebApi/NetMind.WebApi.csproj -c Release -o publish/netmind` | 当前部署文档沿用框架依赖发布；安装包建议改为 `win-x64 --self-contained true`。 |
| 单体 Web 应用包 | `AI文档/部署文档.md` | 推荐先将 WebApi 发布目录和前端 `dist` 放入同一安装目录，由安装器创建快捷方式或服务。 |
| AgentBuild 脚本 | `AiAgent:AgentBuildPath` / 设置页「AgentBuild 脚本设置」 | P5 后 AI Agent 入口依赖外部 AgentBuild `src/agent_kernel.py`，部署时必须同步安装或配置该脚本目录。 |
| Windows 安装器 | WiX Toolset / Inno Setup | 当前仓库尚未引入安装器工程；后续可新增 `installer/` 或 `build/installer/` 存放脚本。 |
| 桌面壳方案 | Tauri / Electron | 适合商业化桌面体验，需额外处理后端进程、端口、自动更新和本地数据目录。 |

## 4. AI Agent 后续模块与基础设施定位

### 4.1 四类用户请求类型

| 类型 | 上下文范围 | 典型权限 | 检索策略 |
| --- | --- | --- | --- |
| 节点聚焦辅助 | 当前节点、父子节点、直接关联节点、当前对话 | 可建议编辑；写入前必须由用户确认 | 优先读取当前节点详情和局部关联，再按需要补充同图近邻。 |
| 思维导图全局辅助 | 当前思维导图全量节点、关联、结构摘要 | 可生成批量编辑方案；实际写库需走工具权限和确认 | 读取当前图结构，必要时做摘要压缩和分块检索。 |
| 数据库全局只读问答 | 全库导图、节点、关联和对话摘要 | 只读，不允许修改数据库 | 走全局搜索/语义检索，只返回引用来源和问答结果。 |
| 软件操作问答 | 当前页面状态、功能说明、接口能力、错误信息 | 只读，允许引导用户点击或解释操作 | 优先检索软件帮助、项目结构速查、接口/页面状态，不读取无关业务内容。 |

### 4.2 当前 AI Agent 入口

| 前端模式 | 后端端点 | 说明 |
| --- | --- | --- |
| 节点问答 Agent | `POST /api/ai/node-agent-chat` | 传入当前节点、父节点链、子节点、关联节点和历史上下文。 |
| 全图问答 Agent | `POST /api/ai/map-agent-chat` | 传入当前导图、全量节点、关联关系和统计信息。 |
| 全局问答 Agent | `POST /api/ai/global-agent-chat` | 不传入导图或节点数据，仅传基础信息、历史上下文和 Agent 记忆。 |
| 应用帮助 | `POST /api/ai/app-help-agent-chat` | 不传说明书原文；在 `focus_context.manual_absolute_path` 提供只读说明书路径，在 `focus_context.learning_log_absolute_path` 提供学习记录路径。Agent 只允许追加学习记录，由管理员统一维护正式说明书。 |

### 4.4 阶段衔接建议

P5.3 已完成基础 Agent 入口接入和普通聊天入口收束。下一阶段目标版本为 v1.7.0，重点补全 Agent SKILL、完善软件整体稳定性和维护体验，形成稳定维护版本。再下一阶段 v2.0.0 进入扩展化，不再按商业化方向规划，重点支持用户、安装包、社区、多端和 Skill/模型生态扩展。

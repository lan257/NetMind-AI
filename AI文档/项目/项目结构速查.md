# NetMind 项目结构速查

更新时间：2026-04-29  
依据文档：`AI文档/项目基础说明.md`、`AI文档/项目研发说明.md`、`AI文档/开发日志.md`、`AI文档/AI大模型配置说明.md`

## 1. 代码定位总览

### 1.1 根目录

| 路径 | 用途 |
| --- | --- |
| `AI文档/` | 项目说明、研发说明、开发日志、AI 配置说明、SQL 和冒烟脚本。 |
| `src/NetMind.sln` | .NET 解决方案入口。 |
| `src/Directory.Build.props` | C# 公共编译配置：`latest`、Nullable、ImplicitUsings。 |
| `src/NuGet.Config` | NuGet 包源配置。 |
| `src/NetMind.Frontend/` | Vue3/Vite 前端项目。 |

### 1.2 后端分层

| 项目 | 职责 | 重点文件 |
| --- | --- | --- |
| `NetMind.WebApi` | HTTP API、依赖注入、全局异常包装、Swagger、静态前端托管。 | `Program.cs`、`Controllers/*.cs`、`Swagger/SwaggerDocumentFactory.cs`、`appsettings*.json` |
| `NetMind.Services` | 业务编排、校验、导入导出、AI 清洗调用。 | `Interfaces/*.cs`、`Implementations/*.cs`、`Configurations/AiCleanOptions.cs` |
| `NetMind.Repository` | PostgreSQL 数据访问。 | `Implementations/*Repository.cs`、`PostgresConnectionFactory.cs`、`Interfaces/*.cs` |
| `NetMind.Models` | DTO、实体、ViewModel。 | `Dtos/*.cs`、`Entities/*.cs`、`ViewModels/*.cs` |
| `NetMind.Common` | 通用响应包装。 | `Responses/ApiResult.cs` |
| `NetMind.IntegrationTests` | 无第三方测试框架的集成验证入口。 | `Program.cs` |

### 1.3 前端分层

| 文件 | 职责 |
| --- | --- |
| `src/NetMind.Frontend/src/App.vue` | 当前主要页面和交互逻辑：导图列表、节点树、节点表单、关联表单、导入导出、AI 清洗。 |
| `src/NetMind.Frontend/src/styles.css` | 三栏布局、表单、列表、状态提示、移动端适配。 |
| `src/NetMind.Frontend/src/main.js` | Vue 应用挂载入口。 |
| `src/NetMind.Frontend/vite.config.js` | Vite 配置与 `/api` 代理到后端。 |
| `src/NetMind.Frontend/package.json` | 前端脚本和依赖：Vue 3.5、Vite 5.4。 |

# 项目基本情况
实现AI辅助的知识图谱工具。
## 项目流程
+ 需求、文档、知识框架通过AI加工及清洗为标准结构。
	+ 需求可通过AI辅助进行结构化拆解
+ 用户调整校验 
	+ 自动校验标准结构并提示AI修正结构。
+ 标准结构导入数据库存储。
	
+ 数据库持久化保存
	
+ 基于数据呈现进行各种操作（集成AI）
	+ 编辑
	+ 导出（分享）
	+ 查询
	+ 节点关联
+ 基于整体知识库提供AI问答。
### 需求、文档、知识框架通过AI加工及清洗为标准结构。
明确的需求文档被AI加工并清洗为可持久化保存的结构化数据结构，用于存储数据库及展示图（思维导图）
#### 需求可通过AI辅助进行结构化拆解
不够完善的需求可以另外通过一个功能实现AI辅助进行结构化解析
#### AI选择
1、在基础款中选择文本逻辑处理能力高的本地模型，如`deepseek`
2、针对付费用户，提供云模型，使用API实现。
### 用户调整校验
在存储数据库前，需要用户进一步确认保存，并允许用户进行基本的修改。
####  自动校验标准结构并提示AI修正结构。
在导入之前对标准结构进行结构校验，并要求AI进行结构化清洗。
### 标准结构导入数据库存储
将结构化数据导入数据库进行持久化保存。
#### 服务器
将数据管理、用户管理及AI调用放在后端，前端基础功能仅用于展示及AI交互的前端逻辑，后续可考虑仅将思维导图数据库内置在本地。

###  基于数据呈现进行各种操作（集成AI）
将数据展示在前端，并基成AI实现各种交互
1. 编辑：通过可视化操作实现对思维导图数据的编辑。
2. 导出（分享）：将思维导图数据进行导出，并提供异端导入功能，甚至提供社区功能。
3. 查询：针对不同的范围进行全局查询，全网、软件全局、本账号、本思维导图、本节点知识卡片，层层之间为包含关系
4. 节点关联：实现跨图进行节点关联，甚至可实现全局的节点关联，可以在节点中快捷查看已关联节点。甚至将节点设置为超链接可直接引用跳转。
### 基于整体知识库提供AI问答。
基于四层不同范围，对其进行AI问答。进一步可提供多模态。
